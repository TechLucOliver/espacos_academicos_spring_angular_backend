Desenvolvimento do Backend do Cenário TED (Versao 03): Sistema de Controle de Espaços Acadêmicos 
para a Disciplina Arquitetura de Software do Curso de Engenharia de Software na UCSal.

**Visão Geral**

O projeto da arquitetura desse sistema inclui uma aplicação Front-End que interage com uma aplicação 
Back-End, a partir de requisições e respostas. Os usuários do sistema farão a interação exclusivamente 
a partir do projeto Front-End. Nessa interação é importante que todo o negócio esteja mapeado e processado 
no back-end e o front-end deverá buscar do back-end o que precisa para apresentar ao usuário final.
